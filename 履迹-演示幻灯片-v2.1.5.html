02方向 / THE DIRECTION

正在流行的做法

把经历、把谈话嵌进知识库，让 AI 彻底读懂自己，帮自己有更好的发展。

但对多数人而言

×不会去使用知识库
×更不用说纯打字把内容输进去
×打字还自带主观色彩，必然有遗漏

03核心 / THREE CORES
三个核心功能
主屏可视化　·　多 AGENT　·　长效录音
01 / GRAPH

星图可视化

分析、排序后的知识库，在主屏以星图铺开。六类行星与时间轴，让大家直观看到自己的所有。

主屏　·　一眼看见
02 / AGENTS

多 Agent 内嵌

内嵌多种不同人格，对应不同用途。同一份记录库，可以换一种视角来追问自己。

人格列表　·　随需切换
≈ 20MIN / 轮
03 / CAPTURE

长效录音模式

按下即持续收音；每约 20 分钟自动跑一次流水线，分析、编写、排序，把庞大录音压成极小的点文字——一个人每天的全部都能刻录进来。

音频 → 点文字　·　无需打字
